# Project Features Overview

This document lists the main features of the Gadget Shop project, organized by domain, to assist in drawing UML diagrams and understanding the system architecture.

## Authentication

- User registration (sign up)
- User login (sign in)
- Forgot password/reset password
- Google Sign-In integration
- Device token management for push notifications

## Products

- View all products
- View product details
- Product categories
- Flash sale products
- Search and filter products

## Cart

- Add products to cart
- Remove products from cart
- View cart contents
- Update product quantity in cart
- Checkout process (if implemented)

## User Profile

- View and edit user profile
- Manage user device token
- View order history (if implemented)

## Home & Navigation

- Home screen with featured products, banners, and categories
- Drawer and navigation between screens
- Splash screen and welcome screen

## UI Components

- Reusable widgets (buttons, carousels, sliders, etc.)
- Custom snackbars and dialogs

## Utilities & Core

- Constants and theme management
- Keyboard management
- Network and error handling
- Firebase integration (core, auth, messaging)
